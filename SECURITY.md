# Security

Do not post credentials, full conversations, authentication files or private
database/log attachments in public issues. For a suspected vulnerability, contact
the repository maintainer privately through an available GitHub contact channel
before disclosing details. A dedicated private reporting channel is not yet configured.

Whip runs as the current OS user and uses Codex's existing execution permissions.
See [privacy](docs/privacy.md) and [recovery rules](README.md#recovery-rules).
